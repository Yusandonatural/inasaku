# 自然栽培の米作り 一年目の教科書

> 家族で食べるお米を、自然栽培で作る。

自然栽培（無農薬・無肥料）で米を一年つくりきるための教科書と、作業暦を自動生成するツールです。

公開ページ: https://inasaku.yusando.com/

## できること

- **最寄りのアメダス観測地点を探す** — 地名検索（国土地理院の地名検索API）、現在地、都道府県一覧の3通り。全国905地点（気温の日別平年値がそろっている現役のアメダス）から緯度経度で最寄りを判定します。
- **気象庁の日別平年値で日付を計算** — 選んだ地点の平年値（1991〜2020年の30年平均）をリポジトリに同梱しており、外部APIを呼ばずに田植え適期・出穂・収穫を積算温度から算出します。
- **その土地に向く品種を判定** — 出穂後20日／40日の平均気温、耐倒伏性、いもち病抵抗性から品種をランク付けします。自然栽培好適種（★）を既定で表示。

## ページの直し方

`index.html` 以外の5ページは `_build/` のスクリプトから生成しています。**HTMLを直接編集せず、`_build/` の中を直してから再生成してください。**

```
cd _build
python3 build.py      # 5ページを書き出す
```

| スクリプト | 生成先 |
|---|---|
| `_build/shell.py` | 共通の枠（ヘッダー・ヒーローSVG・フッター）。全ページが使います |
| `_build/chart.py` | 単一系列のSVGグラフ（棒・折れ線） |
| `_build/p_genjou.py` 〜 `p_sagyou.py` | 各ページの本文 |
| `_build/p_index.py` | `index.html` にヒーローと共通枠をかぶせる（一度だけ実行済み） |

`index.html` は工程表ツールを含む大きなファイルなので、`p_index.py` は**一度だけ**適用する設計です（適用済みなら何もしません）。ツール本体を直すときは `index.html` を直接編集してください。

## ヒーローと見出しの書体

トップのヒーローは `assets/hero.jpg` を背景に敷き、`.hero::after` の2枚のグラデーションで暗く落として文字を読ませています。左に向かって濃く、右にいくほど写真が見えるようにしてあるので、**写真を差し替えるときは主題を右寄りに置いた横位置の写真**を選んでください。スマホでは `assets/hero-sp.jpg` に切り替わり、上下方向のグラデーションに変わります。印刷時は写真を出さず単色になります。

見出しの書体は**しっぽり明朝**（Google Fonts）です。ヒーローのタグライン・大見出し・リード・数字と、下層ページの `.pagehead h1` に当てています。本文はこれまでどおりゴシックのままです。読み込みは各ページの `<head>` にある Google Fonts の `<link>` で、フォントが届かない環境では Noto Serif JP → ヒラギノ明朝 → 游明朝の順に落ちます（`--mincho`）。

## 平年値データの作り方

`climate/*.json` と `amedas-chiten-data.html` は `_build/climate.py` で作っています。気象庁のデータは再配布可なので生成物をリポジトリに入れていますが、平年値が更新されたとき（次は2030年ごろ）は次の手順で作り直してください。

```
# 1. 気象庁の平年値ダウンロードページから normal_amedas_daily.zip を取得して展開
#    https://www.data.jma.go.jp/stats/data/mdrr/normal/
# 2. 日平均気温(要素0500)と日合計降水量(要素4000)の行だけを集める
grep -h -E '^25,[ 0-9]+, *(0500|4000),' area*/*.csv > extract.txt
# 3. 変換（jma_station_active.csv は気象庁の地点データ）
python3 _build/climate.py extract.txt jma_station_active.csv
```

30年ぶんの平年値がそろっていない新しい観測所（2026年時点で11地点）は、計算できないので地点一覧から外れます。

平年値は64進1文字を単位に詰めてあります。1行が「観測所番号,気温367文字,降水72文字」で1地点ぶん（約450バイト）。

- **気温** — 1/1 の値だけ2文字（0.1℃の整数＋400）、以降は**前日との差を1文字**（0.1℃単位＋32）。日別平年値の日々の差は全国どこでも最大0.6℃なので1文字で足ります。復元は完全に元どおり（誤差0）。
- **降水量** — 旬（10日ごと・年36旬）の日平均を2文字ずつ。日別のまま持つと量のわりに使い道がない（期間合計しか使わない）ためです。梅雨期の合計で最大3.6%のずれ。

ファイルを地点ごとに分けると905個になってGitHubのウェブ画面からアップロードできないため、観測所番号の上2桁（＝地域）ごとに63ファイル（合計564KB・最大15KB）へまとめています。ツール側は選ばれた地点の地域ファイル1つだけを読み、`climDecT()` / `climDecR()` で366日ぶんに展開します。「気温が平年より±1℃の年」は平年値をずらして作り、収穫日の幅として表示しています。

グラフは単一系列で、データ色は `#2e8b57` に固定しています。この色は色覚多様性のチェック（彩度・明度帯・背景コントラスト）を通したものです。複数系列にすると識別性の検証が必要になるため、量が違う指標は**必ず別のグラフに分けて**ください。2軸グラフは使いません。

## Shopify との連携

このリポジトリの GitHub Pages を本体とし、Shopify 側のページ本文は `shopify-embed-body.html` に置き換えます。iframe が `https://inasaku.yusando.com/` を読み込むので、**このリポジトリを更新すれば Shopify のページも自動で新しくなります**。

iframe の高さは、子ページから `postMessage` で実際の高さを親に伝えて自動調整しています。現在地の取得を iframe 内で使うため、iframe には `allow="geolocation"` を付けてあります。URL を変える場合は、`shopify-embed-body.html` の `src` と `ORIGIN` の2か所を揃えて直してください。

## Shopify 断片版との違い

Shopify のページ本文（`shopify-page-body.html`）では地点データを `/pages/amedas-chiten-data` から読み込みますが、単体版（`index.html`）は同じフォルダの `amedas-chiten-data.html` から読み込みます。この1行だけが違いです。

```js
const STN_URL = "./amedas-chiten-data.html";   // 単体版
const STN_URL = "/pages/amedas-chiten-data";   // Shopify 版
```

## 計算の根拠

| 項目 | 基準 | 出典 |
|---|---|---|
| 田植えの下限 | 日平均気温 12.5〜14℃（安全側15℃） | 群馬県、山形県、秋田県 |
| 育苗日数 | 中苗 25〜35日 | 群馬県、長野県 |
| 気温・降水量 | 日別平年値（1991〜2020年の30年平均） | 気象庁「アメダス日別平年値」 |
| 出穂 | 移植からの有効積算温度（基準10℃） | 京都市・移植6/10の12品種実測から品種別に算出 |
| 収穫 | 出穂後の積算気温（早生950〜1,000／中生1,000〜1,050／晩生1,050〜1,100℃、籾黄化率85〜90%） | JA全農、岡山県、熊本県、香川県、福井県 |
| 高温登熟障害 | 出穂後20日間の平均気温 26〜27℃超で白未熟粒が増加 | 農研機構、農林水産省、茨城県 |
| 安全出穂晩限 | 出穂後40日間の平均気温 21〜22℃を下回ると登熟不足 | 群馬県、青森県、広島県 |
| 1人あたりの米消費量 | 精米53.4kg／年（令和6年度・供給純食料。前年度50.3kg） | 農林水産省 食料需給表 |
| 玄米→精米 | 歩留まり90%で換算 | — |
| 収量の目安 | 慣行539kg/10a（令和7年産平年収量）、有機348kg/10a（慣行の約72%、300〜480kgが中心） | 農林水産省、鳥取県 |
| 登熟適温 | 出穂後20日間の平均気温 24℃前後、登熟期全体では20〜25℃ | 農研機構、青森県、北海道 |

降水量は、品種の適否を決められる公的な基準が見当たらなかったため判定には使わず、梅雨期の平年降水量の表示と、穂発芽しやすい品種で収穫前の降雨が多い場合の注意喚起にのみ使っています。

## 必要な田んぼの広さの計算（トップの `#ryou`）

家族の人数・1日に食べるごはんの量・見込む収量から、必要な面積を出します。計算は `精米 = 人数 × 1人あたり年間消費量` → `玄米 = 精米 ÷ 0.9` → `面積㎡ = 玄米 ÷ 収量kg/10a × 1000`、確保したい広さは畦と不作の年をみて1.2倍。1反=991.7㎡=300坪=10a、1俵=玄米60kgです。スクリプトは `index.html` の同セクション内に即時関数で入れてあり、工程表ツールとは変数を共有していません。**自然栽培だけを対象にした公的な収量統計はないため、「4俵・5俵」は有機栽培の実態調査の下の帯から置いた目安**である旨を画面にも明記しています。

## データの出典

- アメダス地点データ（観測所番号・地点名・緯度経度・標高）— 気象庁「地点データ」
- 気温・降水量 — 気象庁「アメダス日別平年値（1991〜2020年）」
- 地名検索 — 国土地理院 地名検索API
- 品種特性 — 農研機構イネ品種データベース、各都道府県の奨励品種特性表
- 米の消費量 — 農林水産省「令和6年度食料需給表」
- 収量 — 農林水産省「令和7年産水稲の10a当たり平年収量」、鳥取県「水稲有機栽培事例における収量実態」

外部APIへの依存は、地名検索（国土地理院）だけです。地名で探さずに都道府県一覧や現在地から選ぶ場合は、外部への通信は一切ありません。気温・降水量は気象庁の平年値をリポジトリに同梱しているため、利用料も利用条件の制約もありません。

# 自然栽培の米作り 一年目の教科書

自然栽培（無農薬・無肥料）で米を一年つくりきるための教科書と、作業暦を自動生成するツールです。
株式会社悠三堂 — https://yusando.com

公開ページ: https://yusando.com/pages/inasaku-kyokasho

## できること

- **最寄りのアメダス観測地点を探す** — 地名検索（国土地理院の地名検索API）、現在地、都道府県一覧の3通り。全国916地点（気温を観測している現役のアメダス）から緯度経度で最寄りを判定します。
- **過去5年の実測気温で日付を計算** — 選んだ地点の緯度・経度・標高で日別平均気温と降水量を取得し、田植え適期・出穂・収穫を積算温度から算出します。
- **その土地に向く品種を判定** — 出穂後20日／40日の平均気温、耐倒伏性、いもち病抵抗性から品種をランク付けします。自然栽培好適種（★）を既定で表示。

## ファイル

| ファイル | 用途 |
|---|---|
| `index.html` | 単体で動くWebページ。GitHub Pages などにそのまま置けます |
| `amedas-chiten-data.html` | アメダス916地点の地点名・緯度経度・標高。`index.html` が読み込みます |
| `shopify-page-body.html` | Shopify のページ本文に貼り付ける断片版（`<div id="inasaku-kyokasho">` から始まります） |

`index.html` と `amedas-chiten-data.html` は必ず同じディレクトリに置いてください。

## GitHub Pages で公開する

1. このリポジトリの **Settings → Pages** を開く
2. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

`.nojekyll` を置いてあるので Jekyll の処理は走りません。

## Shopify 版との違い

Shopify のページ本文（`shopify-page-body.html`）では地点データを `/pages/amedas-chiten-data` から読み込みますが、単体版（`index.html`）は同じフォルダの `amedas-chiten-data.html` から読み込みます。この1行だけが違いです。

```js
const STN_URL = "./amedas-chiten-data.html";   // 単体版
const STN_URL = "/pages/amedas-chiten-data";   // Shopify 版
```

## 計算の根拠

| 項目 | 基準 | 出典 |
|---|---|---|
| 田植えの下限 | 日平均気温 12.5〜14℃（安全側15℃） | 群馬県、山形県、秋田県 |
| 育苗日数 | 中苗 25〜35日 | 群馬県、長野県 |
| 出穂 | 移植からの有効積算温度（基準10℃） | 京都市・移植6/10の12品種実測から品種別に算出 |
| 収穫 | 出穂後の積算気温（早生950〜1,000／中生1,000〜1,050／晩生1,050〜1,100℃、籾黄化率85〜90%） | JA全農、岡山県、熊本県、香川県、福井県 |
| 高温登熟障害 | 出穂後20日間の平均気温 26〜27℃超で白未熟粒が増加 | 農研機構、農林水産省、茨城県 |
| 安全出穂晩限 | 出穂後40日間の平均気温 21〜22℃を下回ると登熟不足 | 群馬県、青森県、広島県 |
| 登熟適温 | 出穂後20日間の平均気温 24℃前後、登熟期全体では20〜25℃ | 農研機構、青森県、北海道 |

降水量は、品種の適否を決められる公的な基準が見当たらなかったため判定には使わず、梅雨期の平年降水量の表示と、穂発芽しやすい品種で収穫前の降雨が多い場合の注意喚起にのみ使っています。

## データの出典

- アメダス地点データ（観測所番号・地点名・緯度経度・標高）— 気象庁「地点データ」
- 気温・降水量 — [Open-Meteo](https://open-meteo.com/)（ERA5再解析。観測地点の緯度経度・標高で取得）
- 地名検索 — 国土地理院 地名検索API
- 品種特性 — 農研機構イネ品種データベース、各都道府県の奨励品種特性表

> **注意** Open-Meteo の無料枠は非商用利用が条件です。商用サイトで使う場合は有料プランへの切り替えか、気象庁の平年値を埋め込む方式への変更を検討してください。
